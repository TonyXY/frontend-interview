三条黄金规则

规则 ① · 每个对象都有 __proto__
每个对象（包括函数）都有 __proto__，指向其构造函数.prototype。沿着 __proto__ 一路向上，就能走完整条原型链。实例 foo 找不到的属性，会顺着这条链逐层查找。
规则 ② · 函数都有 prototype 属性
每个函数都有 prototype 属性，指向它创建实例时使用的原型对象。所有普通函数的 __proto__ 都指向 Function.prototype，所以函数也是“Function 的实例”。
规则 ③ · 原型的 constructor 指回函数
Foo.prototype.constructor === Foo。实例自身没有 constructor，是沿链读到原型对象上的 constructor，所以 foo.constructor === Foo。三者形成一个稳定的三角关系。

已用 Node 逐条验证的事实（ground truth）

foo.__proto__ === Foo.prototype → true
Foo.prototype.constructor === Foo → true
foo.constructor === Foo → true
Foo.__proto__ === Function.prototype → true
Object.__proto__ === Function.prototype → true
Function.__proto__ === Function.prototype → true
Function.prototype.__proto__ === Object.prototype → true
Object.prototype.__proto__ === null → true
foo instanceof Object → true
foo instanceof Foo → true
foo.hasOwnProperty('constructor') → false
Foo.prototype.hasOwnProperty('constructor') → true
