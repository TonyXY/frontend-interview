SQL 必会 SELECT / JOIN / GROUP BY / WHERE
SELECT u.name, COUNT(o.id) AS cnt   -- 用户及其订单数
FROM   users u
LEFT JOIN orders o                -- 联表，LEFT 保留左侧全量
  ON   u.id = o.user_id
WHERE  u.status = 'active'        -- 过滤（WHERE 先于分组）
GROUP BY u.id, u.name             -- 分组聚合
ORDER BY cnt DESC                 -- 排序取前 N
执行顺序：WHERE → GROUP BY → HAVING → SELECT → ORDER BY。
Python / pytest 速查 接口自动化最小闭环
import requests, pytest

@pytest.fixture                # 夹具：复用基地址
def base():
    return 'http://api.test'

@pytest.mark.parametrize('n,exp', [(18,True),(17,False)])
def test_age(base, n, exp):
    r = requests.get(f'{base}/check', params={'age':n})
    assert r.status_code == 200
    assert r.json()['ok'] is exp
一句话：requests.get/post 发请求 → assert 断言 → fixture 提共用 → parametrize 铺数据。
性能测试指标 压测关注点 + JMeter 关键词
响应时间请求发出到返回的耗时，关注 avg / p95 / p99 而非单点
TPS每秒事务数（事务=完整业务动作）；QPS每秒查询/请求数
并发数同时处理请求的用户/连接数，与 TPS·响应时间互相影响
错误率失败请求占比，一般要求 < 1%
JMeter：线程组（模拟并发）→ Sampler（请求）→ 断言 → 监听器·聚合报告（读 Throughput / 错误率 / 响应时间）→ 定时器、参数化 CSV 扩展。
