# 谈薪策略

## 一句话解释

谈薪不是"讨价还价"，而是一场**信息不对称的博弈**——你的筹码是市场行情数据、竞品 Offer、以及你的不可替代性，目标是让 HR 觉得"多给 10% 就能锁定一个稳靠谱的人"而不是"再压一压试试"。

## 核心谈判框架

```mermaid
flowchart TD
    A[拿到 Offer] --> B{有竞品?}
    B -->|有| C[了解竞品总包]
    B -->|没有| D[锚定期望区间]
    
    C --> E[计算目标总包<br/>max(竞品, 期望)]
    D --> F[市场行情调研<br/>脉脉/OfferShow/Levels]
    
    E --> G[不先出价<br/>让 HR 先出]
    F --> G
    
    G --> H{HR出价 vs 期望}
    H -->|达到预期| I[谈签字费/职级]
    H -->|低于预期| J[用数据 argue]
    
    J --> K[展示竞品/行情数据]
    K --> L{HR 第二轮报价}
    L -->|OK| I
    L -->|No| M[评估是否接]
    
    I --> N[书面 Offer 确认]
```

## 深入理解

### 1. 谈薪前的准备

**第一步：搞清楚"总包"是什么**

大厂薪资是一个组合包，不只看 base：

| 组成部分 | 说明 | 谈判空间 |
|---------|------|---------|
| **Base 月薪** | 基本工资 | ⭐⭐⭐ |
| **年终奖** | 一般是 1-6 个月，看公司政策 | ⭐ |
| **股票/RSU** | 分 4 年归属，每年 25% | ⭐⭐⭐⭐ |
| **签字费** | 一次性签约奖励 | ⭐⭐⭐⭐⭐ |
| **搬家费/补贴** | 异地入职补贴 | ⭐⭐ |
| **期权** | 未上市公司的期权 | ⭐⭐⭐⭐ |

**总包计算公式：** `Base × (12 + 年终月数) + 年归属股票价值 + 签字费均摊`

**第二步：市场行情调研**

| 渠道 | 用途 | 可靠性 |
|------|------|--------|
| **脉脉** | 匿名薪资爆料，了解职级对应范围 | 中 |
| **OfferShow** | 应届生到大厂的薪资数据 | 中高 |
| **Levels.fyi** | 对标国际大厂的薪资等级 | 高 |
| **身边人脉** | 前同事/同行的一手信息 | 最高 |

**第三步：确定你的 BATNA（最佳替代方案）**

- 没有 Offer 的时候不要裸辞谈薪——你没有底气
- 最好的状态是：**手里至少有一个保底 Offer，再去冲击更好的**

### 2. 谈判策略

#### 为什么不要先出价？

心理学中的"锚定效应"——谁先出价，谁就锚定了谈判区间。

- ❌ "我的期望是 50k"
  - HR 心想："本来预算 55k，你说 50k 那就 50k 吧，省 5k"
- ✅ "根据市场行情和我的经验，我期望总包在 80-100 万之间，具体看整体 package 构成"

#### 如何应对"你的期望薪资是多少"

这是 HR 的第一个问题，也是最关键的问题。

**标准回答框架：**
```
"在谈薪资之前，我想先了解一下这次招聘的职级范围和
这个职级的标准薪资区间，这样我能给出一个合理期望。
同时我目前还有其他面试在走，我会综合 Offer 来做决定。"
```

**如果 HR 坚持先要数字：**
```
"我目前了解了市场行情，针对我这个级别和经验的资深前端，
合理的总包范围在 XX-XX 之间。具体还要看职级、股票
和整体 package 构成，我比较灵活。"
```

#### 多 Offer 怎么 Leverage

多 Offer 是最好的谈判筹码，但用法有讲究：

| 策略 | 做法 | 效果 |
|------|------|------|
| **时间差** | 让 A 家先出 Offer，拖时间等 B 家 | ⭐⭐⭐ |
| **直接 PK** | "B 家给了 XX，你能 match 吗？" | ⭐⭐⭐⭐ |
| **书面展示** | 展示竞品 Offer letter（可打码） | ⭐⭐⭐⭐⭐ |
| **综合比较** | "我更倾向你家，但总包差 20%，能否 close 这个 gap？" | ⭐⭐⭐⭐ |

#### 签字费谈判技巧

签字费是 HR 最有灵活空间的预算，也是你最容易争取到的：

- "如果可以的话，能否加一笔签字费来 cover 我因为跳槽损失的未归属股票/年终奖？"
- 签字费一般可以要 **1-3 个月 base**，上限看公司政策

### 3. 常见谈判场景及应对

| 场景 | HR 话术 | 你的回应 |
|------|---------|---------|
| **HR 压价** | "这个级别预算有限" | "我理解，那能否帮我争取更高职级？或者看看签字费和股票有没有空间？" |
| **当前包太低** | "你目前 base 太低，涨幅不能超过 30%" | "我的期望是基于市场行情和我的能力，不是基于当前薪资。如果贵司薪资体系有严格限制，能否通过签字费/RSU 来弥补？" |
| **展示竞品** | "那你去那边吧" | "我其实更倾向贵司的业务方向和团队氛围，但如果薪资差距太大（>20%），从家庭角度很难做出选择。能否帮忙再争取一下？" |
| **没有竞品** | "没有其他 Offer 的话这个价已经很好了" | "虽然目前没有正式 Offer，但还有几家在终面阶段。我希望能尽快敲定，如果 package 合适我立即签" |
| **争取职级** | "职级是定好的不能变" | "我理解职级体系有标准，那能否在这个职级给到 range 的上限？或者半年后做 fast promotion review？" |
| **僵持不下** | "这个价格我没办法再高了" | "我理解，要不这样——总包维持这个数，但能否增加一笔签字费或者入职奖金来 close 这个 gap？" |

### 4. 大厂薪资范围参考（2026年）

| 公司 | P6/P7 级别 | Base 月薪 | 总包范围 |
|------|-----------|-----------|---------|
| 字节跳动 | 2-1 / 2-2 | 35k-55k | 60-100 万 |
| 阿里巴巴 | P6 / P7 | 30k-50k | 50-90 万 |
| 腾讯 | 9-10 级 | 30k-55k | 55-95 万 |
| 美团 | L7 / L8 | 35k-50k | 55-85 万 |
| 百度 | T5 / T6 | 30k-48k | 50-80 万 |

## 面试问法

- 🔥 **谈薪的核心原则是什么？**
  - **Never give the first number**——让 HR 先出价，你才有谈判空间
  - 用 **Data Point** 说话——市场行情、竞品 Offer、你的量化成果
  - **多 Offer 才有谈判筹码**——至少有一个保底 Offer 再谈
  - **总包思维**——不只看 Base，综合评估 RSU + 签字费 + 年终奖

- ⭐ **什么时候是谈薪的最佳时机？**
  - HR 发口头 Offer 时——这是最具灵活性的窗口
  - 有了书面 Offer 但还没签时——你有选择权，HR 有 KPI
  - 有竞品 Offer 介入时——多 Offer 交替推进

- ⭐ **什么情况不该谈薪？**
  - 没有其他 Offer 也没有明确的市场数据时
  - 面试表现一般，公司本来就在犹豫时
  - 你还处于"求这个 Offer"的阶段时
